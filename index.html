オセロ棋譜ビューア

f5d6c3… 形式の棋譜を貼り付けて、1手ずつ盤面で並べられます。

← → キーでも1手ずつ動かせます。盤上の点（打てる場所）をクリックすると、その局面から別の手を試せます。

棋譜

1手は「列 a〜h（左→右）＋行 1〜8（上→下）」で書きます。大文字・小文字、空白、手数の数字は無視します。パスは省略できます（PA / PS と書いても構いません）。⌘ / Ctrl + Enter でも読み込めます。

手順

    使い方

    1. 「棋譜」欄に棋譜を貼り付けて「盤に並べる」を押します。
    2. ◀ ▶ ボタン、スライダー、← → キーで1手ずつ進めたり戻したりします。
    3. 「手順を表示」をオンにすると、石に手数の番号が出ます。
    4. 盤上の打てる場所をクリックすると、その局面から別の手を検討できます。
    5. 「共有リンクをコピー」で、棋譜と表示中の手数を含んだ URL をコピーできます。

    URL で棋譜を開く

    URL の kifu に棋譜を、move に手数を付けると、その局面から開けます。move を省くと最後の局面を表示します。

    例：?kifu=f5d6c3d3c4&move=3

    アドレスバーの URL は、表示中の棋譜と手数に合わせて自動で更新されます。
